# Cotype fix plan (2026-09-11)

## Why earlier sessions failed

- The reference apps (TabType, KeyType, cotabby) were studied once as a
  read-only summary. Workers then got "reference only" briefs with narrow
  file ownership. Nobody ported the mechanics that make those apps work.
- Most effort went to release, Sparkle, privacy, and safety hardening
  (19k lines). The core loop was never run end to end by a person.
- The user asked for automatic suggestions on 2026-09-10. The controller
  worker kept `autoSuggestEnabled = false`. Typing never starts a suggestion.
- Every fail-closed exit is silent. No log says why nothing appeared, so
  nobody could debug it.

## Evidence

- `CompletionInteraction(autoSuggestEnabled: false)` in production.
- Live metrics: Ghostty 11,139 failed vs 4 accepted; Helium (Chromium)
  3,464 failed vs 7 accepted.
- Model is fine: gemma-it warm on 127.0.0.1:8079, 0.15-0.4 s per suggestion.
- Model output has no leading space ("by" + "the end" -> "bythe end") and
  repeats partial words ("questi" -> "questions").

## What the reference apps do that Cotype does not

| Mechanic | Refs | Cotype |
|---|---|---|
| Suggest while typing (debounce 15-90 ms, settle before paint) | all 3 | off |
| AX messaging timeout 50 ms | TabType, cotabby | none |
| Wake Chromium/Electron AX (`AXManualAccessibility`, `AXEnhancedUserInterface`) | all 3 | none |
| Terminals (Ghostty etc.) off by default | all 3 | on, fails silently |
| Caret: zero-length bounds trusted only near previous-char anchor; web prefers anchor | TabType, KeyType | no cross-check |
| Word-boundary reconcile (space / mid-word strip) | all 3 | none |
| Few-shot `Input:/Output:` chat prompt with mid-word examples | TabType (from Cotypist binary) | bare prefix |
| Reason string on every hide/suppress | cotabby | none |

## Fixes (this pass)

1. Turn automatic suggestions on (setting `autoSuggest`, default on). Debounce 120 ms.
2. AX reliability: 50 ms messaging timeout; wake Chromium/Electron AX once per pid.
3. Terminals off by default. A per-app override can turn one back on.
4. Caret ladder: anchor cross-check and sane-rect validation.
5. Prompt: TabType-style few-shot `Input:/Output:` prompt (A/B tested on gemma-it).
6. Caret boundary reconcile: add the missing space, strip a repeated partial word.
7. Diagnostics: content-free `os_log` reason at every fail-closed exit
   (`log stream --predicate 'subsystem == "com.tristan.cotype"'`).

## Later (not this pass)

- Pixel occupancy / baseline probe (TabType `GhostAppearanceProbe`).
- Ghostty inline geometry (no `AXBoundsForRange`; would need cell math).
- KV-prefix reuse, base-model + FIM path (KeyType, cotabby).
- Stability gate and slide-on-accept (cotabby).

## Status check (2026-09-25)

Checked in code and with the new end-to-end test (`EndToEndPipelineTests`).

| Fix | Landed? | Evidence / gap |
|---|---|---|
| 1. Auto-suggest on, 120 ms debounce | Yes | `AppDelegate` registers `autoSuggest = true`; `debounceInterval = 0.12`. |
| 2. AX 50 ms timeout, Chromium/Electron wake | Yes | `AXWake` (Helium `net.imput.helium` listed; Slack detected as Electron). |
| 3. Terminals off by default | Yes, but overridden | `app-overrides.json` turns Ghostty on. Saved metrics: Ghostty 11,448 of 16,971 failures. |
| 4. Caret ladder with anchor cross-check | Yes | `CaretPlacement.reconcileCaret`. |
| 5. Few-shot `Input:/Output:` prompt | Yes, replaced | Measured 37.9% valid on the gate today. Default is now plain continuation (75.9%). |
| 6. Boundary reconcile | Yes, with a bug | It added a space after `.` in code (`res.` + ` json()`). Continuation output now keeps the model's own boundary. |
| 7. Reason on every exit | Partly | Missing on dismissals, empty results, empty layout, and insert failures. Added. |

Root cause found on 2026-09-25 that the plan missed: Local Models unloads
`gemma-it` after 30 idle minutes, and Cotype streams from llama-server
directly, which the daemon does not count as use. So the model went cold
during the day and every suggestion failed with "not loaded" until it was
warmed by hand. `LocalModelsWarmer` now asks the daemon to load it when cold
and refreshes the idle clock every 10 minutes while Cotype is used.
